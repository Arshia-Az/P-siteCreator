# 🚀 P-SiteCreator

A WordPress-inspired Content Management System (CMS) built with Python and Django.

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Django](https://img.shields.io/badge/Django-092E20?style=for-the-badge&logo=django&logoColor=white)

## 📖 About the Project

P-SiteCreator is a custom Content Management System inspired by WordPress, designed to simplify website creation, customization, and content management.

## 🎯 Project Goals

- Website creation and customization
- Dynamic content management
- User-friendly management interface
- Scalable backend architecture
- Simplified website administration

## 🛠️ Technologies

- Python
- Django

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Arshia-Az/P-siteCreator.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Apply database migrations:

```bash
python manage.py migrate
```

Start the development server:

```bash
python manage.py runserver
```

Open your browser:

http://127.0.0.1:8000/
